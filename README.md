# Day 24: Data Type Cleaning Using Pandas

## Objective

To identify incorrect data types in a dataset and convert them into appropriate data types using Python and Pandas.

## Tools Used

* Python
* Pandas
* Jupyter Notebook

## Description

In this task, I worked with an employee dataset containing employee names, ages, salaries, and experience. I checked the original data types and converted the Age, Salary, and Experience columns from string data types to integer data types.

## Steps Performed

1. Created an employee dataset.
2. Checked the original data types using `df.dtypes`.
3. Converted columns using `astype(int)`.
4. Verified the corrected data types.
5. Calculated average age, salary, and experience.
6. Generated statistical summaries using `df.describe()`.
7. Saved the cleaned dataset as a CSV file.

## Key Learnings

* Understanding data types in Pandas.
* Identifying incorrect data types.
* Converting string values into integers.
* Calculating averages and statistical summaries.
* Saving cleaned data into a CSV file.

## Output

The data types of the Age, Salary, and Experience columns were successfully converted to integer types. The cleaned dataset was saved as `cleaned_employee_data.csv`.

## Conclusion

This task helped me understand the importance of correct data types in data analysis and how Pandas can be used to clean datasets.
